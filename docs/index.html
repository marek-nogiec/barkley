Why Barkley

Small, fast, and yours
to extend.

No account, no telemetry, no background indexing. Barkley waits in the menu bar and asks its plugins only when you type.

Instant

Double-tap ⌘ or press ⌥Space. The panel pops up in tens of milliseconds and idles at about 18 MB.

Native Liquid Glass

Real AppKit and NSGlassEffectView, written in Rust. It looks and feels like Spotlight, with springy micro-animations.

Plugins in any language

A plugin is a folder with a manifest and an executable that prints JSON. Shell, Rust, Python, anything.

Fuzzy, ranked results

Every plugin answers in parallel. Results are ranked together, and ⌘1–⌘9 runs any row instantly.

Persistent plugins

Plugins with slow startup stay running and answer over stdin, so even CoreAudio lookups keep up with typing.

Open source

GPL-3.0-or-later, with a supply-chain gate on every dependency. Read every line before you run it.

Bundled plugins

Useful the moment it starts.

Web search, unit conversion, audio devices, quitting apps and emptying the Trash, all built as ordinary plugins you can copy.

Write your own

A plugin is a folder
and a script.

Barkley passes what you typed as an argument and reads rows back as JSON. Each row can open a URL, copy text, or run a command. Need speed or system APIs? The Rust SDK is a few lines.

Plugin guide →

plugins/hello/manifest.toml 
name = "Hello"
keyword = "hi"
run = "./run.sh"
plugins/hello/run.sh 
#!/bin/sh
# Barkley runs this with what you typed after "hi".
cat <<JSON
{"items": [{
  "title": "Hello, $1!",
  "icon": {"symbol": "hand.wave"},
  "action": {"type": "copy", "text": "Hello, $1!"}
}]}
